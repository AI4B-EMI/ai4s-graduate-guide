# 延伸阅读

[返回首页](../README.md)

本模块按知识缺口查阅，**不将数学与数值方法纳入统一主课程，不要求先学完再开展课题**。相关模型的变量、公式、假设和物理意义仍需要在主方向中理解。

## 遇到什么问题时补什么

| 遇到的问题 | 可补充的知识 | 对应研究 |
| --- | --- | --- |
| 不理解矩阵、特征值、降维或张量形状 | 线性代数、矩阵与基本张量运算 | 机器学习、电子结构、数据处理 |
| 不理解梯度、反向传播、优化或误差方向 | 微积分、链式法则、优化基本思想 | 深度学习、参数拟合、设计 |
| 不理解噪声、独立样本、误差与不确定性 | 概率统计、相关性、估计与采样 | MD、机器学习、实验比较 |
| 不理解边界条件、离散、稳定性和收敛 | 常微分/偏微分方程及数值方法相关主题 | 相场、P2D、动力学模拟 |
| 不理解电子态、能量与近似 | 量子力学与电子结构基本概念 | DFT、MLFF 的数据来源 |
| 不理解自由能、系综、平均量与涨落 | 热力学与统计力学 | MD、自由能、相场与电化学 |

## 硕士与博士学习深度

| 硕士 | 博士 |
| --- | --- |
| 以理解当前模型、公式与数据分析为目标，补齐使用中的概念缺口 | 以理解主方向的推导、近似、误差和方法改进为目标，选择相关主题深入 |

学位本身不意味着必须通读全部数学课程。若研究贡献依赖某种数值方法、统计假设或理论推导，应对其有足够深入的掌握。
