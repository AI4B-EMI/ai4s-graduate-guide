# DSH（DeepSeek Harness）阅读指南

## 需要理解的概念

DSH 是 DeepSeek Harness 的简称。官方将其定位为开源 Agent Harness，以插件组织模型、工具、会话、权限等能力。理解 Harness 的用途，有助于区分模型本身的能力与运行环境提供的能力。参见[官方介绍](https://deepseek.com/harness/)。

入门时重点了解：工作目录、会话、模型提供方、工具、权限、插件及运行日志。更换模型、增加工具、改变插件或指令，可能分别影响任务行为；这些变化应在研究记录中说明。

## 推荐阅读顺序

1. 阅读官方介绍，建立“模型＋运行环境”的认识。
2. 阅读仓库 README 的运行与文档入口，了解本组采用的运行方式。
3. 通过官方文档理解会话、配置、工具和插件的用途。
4. 仅在科研智能体课题涉及框架开发时，深入架构和开发文档。

DSH 官方仓库当前标注为开发者预览，可能出现兼容性变化。因此，本组宜单独记录所用版本与配置；本页不将某个社区插件当作默认必装项。版本状态见[官方仓库](https://github.com/deepseek-ai/deepseek-harness)。
