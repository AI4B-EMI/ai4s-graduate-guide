# Codex 阅读指南

[返回模块](README.md) · [返回首页](../README.md)

学习范围：**基本协作为全员基础，扩展配置为课题相关**。

## 阅读主线

1. 认识本组实际使用的 Codex 入口，理解工作目录、会话、文件与工具之间的关系。
2. 学习怎样提供问题背景、相关文件和清晰的完成标准。
3. 理解项目说明如何持续提供上下文；认识 README 和 `AGENTS.md` 的不同用途。
4. 理解修改差异、运行检查和结果解释，知道何时需要继续核验。
5. 按需认识 Skills 与 MCP：前者组织可复用的工作步骤，后者连接外部工具与数据能力。

## 重点理解

README 面向项目使用者说明问题、文件和运行方式；`AGENTS.md` 为 Agent 提供持久项目约定。两者应一致，但不必重复全部内容。具体指令查找与生效规则以官方文档为准。

上下文应优先包含可信来源和关键约束：数据字典、模型说明、参数来源、软件版本与运行方法。将大量资料放入目录并不意味着 Agent 已经阅读和理解全部内容。

对于模拟与数据分析任务，应同时描述“想得到什么”和“为什么这样做”。例如处理扩散系数时，温度、单位、时间区间和拟合对象都可能影响科学含义。
