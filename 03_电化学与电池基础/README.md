# 电化学与电池基础

[返回首页](../README.md) · [主教材阅读说明](教材阅读说明.md)

学习范围：**基本概念为全员基础，机制与模型深入为课题相关**。以《电极过程动力学》为主要教材，建立对电极界面、反应动力学和输运的系统认识。

## 知识清单与分层深度

| 主题 | 硕士：了解基本概念 | 博士：深入掌握 |
| --- | --- | --- |
| 电势与平衡 | 电极电势、电化学势、平衡电势、参比电极及电势标度 | 理解电势与化学势的关系、平衡关系的前提和比较不同计算/实验电势时的约定 |
| 界面结构 | 双电层、电容、吸附及其对反应的影响 | 理解界面模型假设、局部环境和吸附如何改变反应行为 |
| 电荷转移动力学 | 交换电流密度、过电位、传递系数、Butler–Volmer 与 Tafel 关系的物理含义 | 理解关系式的来源与适用区间，识别复杂体系中使用简单表达式的限制 |
| 传质与极化 | 扩散、迁移、对流、浓差极化、欧姆损失 | 分析反应与传质耦合、边界条件、控制步骤和不同时间尺度 |
| 复杂电极过程 | 多步骤反应、反应级数、吸附中间体、控制步骤 | 理解机理推断的证据与非唯一性，比较竞争路径和替代解释 |
| 电化学表征 | 极化曲线、循环伏安、阻抗等方法测量什么 | 理解模型依赖、参数可辨识性以及不同表征证据的相互约束 |
| 电池行为 | 容量、倍率、SOC、SOH、充放电曲线及常见衰退概念 | 连接材料、界相与器件行为，分析性能限制和模型适用范围 |

博士的深入首先聚焦主课题：做界相反应需要重视界面和机制；做 P2D 需要重视输运与反应耦合。硕士涉及这些问题时，也需补齐相应的关键知识。

## 怎样连接研究方向

DFT 与 MD 中的能量、结构和输运信息，需要放在具体电化学条件下解释。相场中的反应项与自由能，需要明确物理含义。P2D 中的界面反应和输运参数，需要理解其定义、条件与来源。AI 学到的结构与性能关系，也应回到这些过程判断是否合理。

容量、倍率、温度、电压窗口与测试条件应结合理解；不同论文中的指标只有在定义与条件可比时才适合直接比较。
