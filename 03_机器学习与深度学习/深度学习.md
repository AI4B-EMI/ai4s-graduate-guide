# 深度学习

[返回模块](README.md) · [MLFF](../05_模拟仿真基础/MLFF/README.md)

主教学视频采用李宏毅机器学习/深度学习系列课程。建议按主题阅读，结合文字资料理解术语、公式与网络结构，不按课程年份叠加学习负担。

## 推荐主题与顺序

| 阶段 | 主题 | 需要理解的内容 |
| --- | --- | --- |
| 全员基础 | 深度学习介绍、回归与分类 | 网络、参数、损失函数与预测任务 |
| 全员基础 | 训练与反向传播 | 梯度、链式法则的用途、优化器、学习率与训练过程 |
| 全员基础 | 训练失败与泛化 | 欠拟合、过拟合、数据处理、正则化、验证与诊断 |
| 架构概览 | CNN、自注意力与 Transformer | 各架构利用何种结构或信息；了解输入与归纳偏置 |
| 课题相关 | 图神经网络、等变模型 | 原子结构、几何信息、对称性与物理约束 |
| 课题相关 | 自监督、生成模型、迁移学习等 | 训练目标、数据来源与设计任务的关系 |

不将所有架构设为全员深入要求。做 MLFF 应重视几何与对称性；做连续模型代理应重视输入输出、边界/工况和外推；做逆向设计应重视候选约束与独立验证。

## 学习深度

| 硕士 | 博士 |
| --- | --- |
| 解释网络怎样从数据学习，理解损失、训练曲线与泛化；看懂课题所用网络的输入输出与主要组成 | 理解主方向架构的设计理由、归纳偏置与训练限制；分析对照、消融、数据覆盖与外推，判断改进来自哪里 |

两类学生都应理解关键数据和模型选择，即使代码由 Agent 辅助生成。博士的深入不等于统一要求从零实现完整深度学习框架。
