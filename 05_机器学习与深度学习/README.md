# 机器学习与深度学习

[返回首页](../README.md) · [传统机器学习](传统机器学习.md) · [深度学习](深度学习.md)

学习范围：**数据、学习与评价的基本概念为全员基础；特定模型与设计方法按课题深入**。传统机器学习和深度学习共同构成方法基础，不能只了解神经网络。

## 全员需要补齐的知识

- 样本、特征、标签、监督/无监督学习，回归与分类。
- 训练集、验证集、测试集，交叉验证、超参数与数据预处理。
- 拟合、泛化、欠拟合、过拟合、正则化与数据泄漏。
- 基线、评价指标、不平衡数据、分布变化与外推。
- 不确定性与可解释性的基本含义及其限制。

材料数据的样本单位需要说明：不同结构、同一结构的不同构型、同一轨迹的相邻帧，并不代表相同程度的独立信息。数据划分要对应实际研究问题，例如预测同体系新样本、跨组成预测或跨工况应用。

## 学习深度

| 内容 | 硕士 | 博士 |
| --- | --- | --- |
| 共同概念 | 理解数据与模型的关系，知道泛化评价与泄漏问题 | 分析划分方式、分布变化、数据偏差及其对结论的影响 |
| 传统机器学习 | 理解常用模型的基本思想与适用问题 | 比较模型假设、数据效率、表示与不确定性，解释方法选择 |
| 深度学习 | 理解网络、损失、训练与泛化的基本过程 | 深入主方向的架构、归纳偏置、训练行为与泛化边界 |
| 科学应用 | 将模型指标与科学目标区分 | 判断预测改善是否转化为机制、设计或方法价值 |

贝叶斯优化、生成模型、逆向设计、图神经网络和等变模型等放在具体课题中扩展；需要的数学知识查[延伸阅读](../07_延伸阅读/README.md)。
