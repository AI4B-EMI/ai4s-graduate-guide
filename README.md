# AI4S 研究生入门指南

面向材料专业背景、开展 AI 驱动电池设计研究的硕士与博士研究生。

**以模拟仿真为根基，发展 AI 驱动的新方法、新设计和新范式。电池是近期验证场景，可迁移方法是长期资产。**

本指南说明需要补齐哪些知识、为什么学习、学到什么深度，以及到哪里查阅资料。练习、方法复现和能力培养融入实际课题，本仓库不设置作业、考试或成果提交要求。

## 怎样理解学习范围

- **全员基础**：所有学生应了解的概念、工具和科研原则。
- **课题相关**：在相应课题中深入，内容与深度随研究需要增加。
- **延伸阅读**：遇到具体知识缺口时查阅，不列为统一前置要求。

每页的硕士、博士要求是建议的学习深度。硕士以建立概念、理解方法和正确使用为重点；博士进一步掌握假设、机制、适用边界与方法选择依据。相关课题所需的关键知识，两类学生都需要深入掌握；博士也无须同时精通五类模拟方法。

## 使用资料的原则

优先阅读每页标出的主资料和推荐范围，再按需查阅补充资料。教材用于建立系统认识，官方手册用于查参数与软件行为，课题组经验资料用于连接实际研究。会运行软件、程序没有报错，都不足以证明科学结论成立。

[厦门大学程俊课题组 Wiki](https://wiki.cheng-group.net/)是推荐的中文综合入口，覆盖计算环境、DFT/MD、机器学习势、文献阅读与科研写作；其中集群路径和组内规定仅适用于其自身环境。
