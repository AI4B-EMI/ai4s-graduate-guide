# 计算工具基础

[返回首页](../README.md) · [接着阅读：LLM 与 Coding Agent](../02_LLM与Coding_Agent/README.md)

学习范围：**全员基础**。重点是能够理解 Agent 操作的对象、看懂常见脚本和日志，并与计算环境正确交互。复杂程序开发随实际课题学习。

## 知识清单

| 工具 | 需要了解的内容 | 初期可暂缓的内容 |
| --- | --- | --- |
| Python | 变量与类型、列表与字典、判断与循环、函数、模块、文件读写、异常、虚拟环境；NumPy 数组与维度、基本绘图 | 复杂继承体系、元编程、性能优化和软件框架设计 |
| Git | 仓库、工作区、提交、差异、历史、拉取推送、分支、冲突的基本含义、恢复、忽略规则 | 复杂历史重写、底层对象与大型协作策略 |
| Linux | 绝对与相对路径、文件操作、通配符、权限、进程、环境变量、管道与重定向、SSH/SCP、日志 | 系统管理、内核、复杂 Shell 编程 |
| Slurm | 登录与计算节点、分区、CPU/GPU/内存/时间、任务提交与状态、取消、输出日志 | 调度器部署、集群管理员配置 |

Python 尤其要理解数组形状、单位和文件来源。Git 要理解每次变更保存了什么，恢复操作影响哪些文件。Linux 要知道当前所在目录、命令影响范围以及报错来自哪个环境。

Slurm 常见命令包括 `sbatch`、`squeue`、`sacct` 和 `scancel`。命令的基本用途可查官方资料，账号、分区、资源限制和脚本头部以本组集群为准。

## 学习深度

| 内容 | 硕士 | 博士 |
| --- | --- | --- |
| Python | 看懂常见数据处理脚本、函数调用和报错；理解输入输出 | 在此基础上理解研究程序的结构、数据流与关键实现；按课题深入 |
| Git | 理解版本保存、差异查看与基本协作 | 能判断代码、参数和结果的版本关系，理解多人或 Agent 修改的追溯要求 |
| Linux | 理解远程登录、文件传输和任务日志 | 理解环境、进程和权限对计算可复现性的影响 |
| Slurm | 理解任务资源与状态，识别常见失败原因 | 理解资源选择、并行设置及批量计算对研究流程的影响 |

工具基础的范围对硕士与博士基本一致。博士的深入体现在研究流程判断，不以掌握复杂编程技巧为统一要求。

## 与 Coding Agent 的关系

Agent 可以帮助编写脚本和提交文件，但学生需要理解文件路径、命令用途、资源请求和日志结果。运行前应知道所用环境；运行后应能区分语法错误、环境问题、资源不足和科学模型问题。
