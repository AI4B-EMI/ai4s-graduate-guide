# MD：分子动力学

[返回模拟模块](../README.md) · [返回首页](../../README.md)

学习范围：**概览为全员基础；原子运动、结构、输运与电解液相关课题深入**。

## 要补齐哪些知识

- 经典运动方程、势函数、力与时间积分；经典 MD、从头算 MD 和 MLFF 驱动 MD 的关系。
- NVE/NVT/NPT 系综、温压控制、周期性边界与时间步长。
- 力场参数、长程相互作用、截断、约束与单位体系。
- 初始结构、平衡过程、生产采样、独立样本与统计误差。
- 径向分布函数、配位数、均方位移、扩散系数和时间关联。
- 尺寸、采样时间及稀有事件对结论的限制。

常见电池问题包括溶剂化结构、离子聚集、扩散与界面局部结构。结构指标与动力学指标回答的问题不同，不能仅凭某一配位特征推断输运性能一定改善。

## 学习深度

| 硕士 | 博士 |
| --- | --- |
| 理解势函数、系综和采样的含义；知道结构及扩散指标怎样定义；理解平衡与生产阶段的区别 | 分析势函数适用范围、采样充分性、有限尺寸与统计相关；深入主课题所需的输运理论或自由能方法 |

理解扩散系数时应关注拟合时间区间、单位、周期边界处理与统计误差。计算电导率时，需区分涉及离子相关的理论表达与独立离子近似，不能自动用扩散系数替代全部输运信息。
