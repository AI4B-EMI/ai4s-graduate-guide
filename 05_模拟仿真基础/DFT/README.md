# DFT：密度泛函理论

[返回模拟模块](../README.md) · [返回首页](../../README.md)

学习范围：**方法概览为全员基础；电子结构、材料与界面反应相关课题深入**。

## 要补齐哪些知识

- Born–Oppenheimer 近似、电子密度、Kohn–Sham 思路与交换关联泛函。
- 基组、平面波截断、赝势、周期性边界与 k 点采样。
- 自洽计算、结构/晶胞优化、能量与力及收敛条件。
- 自旋、色散、DFT+U 等处理的用途与体系依赖性。
- 总能差、吸附能、反应能与迁移/反应能垒的定义。
- 表面、界面、溶剂与带电体系建模时的物理约定。

电池中的用途包括材料稳定性、离子迁移、分子反应及界面相互作用。总能量、自由能和电化学条件下的反应驱动力应区分；静态计算给出的结论需要说明温度、溶剂、熵与电势等因素是否被纳入。

## 学习深度

| 硕士 | 博士 |
| --- | --- |
| 理解 DFT 能计算什么；知道泛函、基组/赝势与收敛参数的含义；看懂主课题中的结构与能量比较 | 理解主要近似的依据和失效情形；判断方法与体系的匹配；分析界面、电荷、参比及自由能处理对机制结论的影响 |

涉及关键能量差时，两类学生都需理解比较对象的一致性、结构和电子收敛、尺寸与采样影响。原子结构合理不等于电子或化学状态一定合理。
