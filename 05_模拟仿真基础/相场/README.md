# 相场：微结构与界面演化

[返回模拟模块](../README.md) · [电化学基础](../../04_电化学与电池基础/README.md)

学习范围：**物理概览为全员基础；相分离、沉积和界面演化课题深入**。

## 要补齐哪些知识

- 序参量、守恒与非守恒场，连续描述与弥散界面。
- 体自由能、梯度能、界面能与化学势。
- Allen–Cahn 与 Cahn–Hilliard 方程各描述什么过程。
- 迁移率、动力学系数、初始条件与边界条件。
- 各向异性、弹性、电场、输运和界面反应等耦合项。
- 界面宽度、空间/时间离散及尺寸对形貌和动力学的影响。

电池相关应用包括材料相分离、锂沉积和界面演化。类似的图像可能由不同模型与参数产生，因此形貌相似不足以单独证明机制正确。

## 学习深度

| 硕士 | 博士 |
| --- | --- |
| 理解序参量、自由能与演化方程的物理意义；知道参数和边界条件怎样影响结果 | 理解变分思路、守恒与耗散；分析耦合项和尺度选择的合理性；判断界面近似与参数对物理解释的影响 |

不要求统一完成偏微分方程和数值方法课程，但相关课题学生需要理解自己模型中的各项、边界条件、守恒及收敛检查。
