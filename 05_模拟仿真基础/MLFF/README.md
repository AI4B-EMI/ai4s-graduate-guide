# MLFF / MLIP：机器学习原子间势

[返回模拟模块](../README.md) · [机器学习基础](../../03_机器学习与深度学习/README.md)

学习范围：**基本概念为全员基础；势开发与应用课题深入**。

## 要补齐哪些知识

- 势能面与能量、力、应力的关系；MLFF 与 MD 积分器承担的不同角色。
- 原子环境描述、平移/旋转/置换对称性，以及不变性与等变性的区别。
- 标注数据的物理来源、组成与结构覆盖、温度/压力/化学环境。
- 训练/验证/测试划分、损失函数、不同标签权重与数据一致性。
- 主动学习、模型分歧、异常构型发现与重新标注。
- 内插、外推、长程作用、反应与电荷变化等适用边界。
- 误差指标、动力学稳定性与目标性质验证之间的关系。

临近轨迹帧往往高度相关。随机拆分帧可能高估对新结构或新条件的泛化能力；应理解按体系、构型族或独立轨迹划分的目的。

## 学习深度

| 硕士 | 博士 |
| --- | --- |
| 理解数据—训练—验证—应用流程；能解释能量与力误差的含义；理解应用范围受数据覆盖限制 | 深入表示方法、对称性、数据选择与主动学习；分析误差如何影响目标性质，并判断模型改进是否具有可迁移价值 |

训练误差低不能直接证明反应能垒、扩散或长期轨迹可靠。使用者也需要理解所采用模型的训练范围，不能只由开发者承担这一判断。
