## 研究定位

我们以物理理解与模拟仿真为基础，研究 AI 如何改善方法、发现设计和改变科研流程。近期围绕电池开展验证，长期积累能够迁移到其他材料和器件体系的方法。

| 主线 | 典型问题 | 重点关联知识 |
| --- | --- | --- |
| 新方法 | MLFF/MLIP 开发；AI 与 P2D、相场融合；数字孪生 | 模拟模型、机器学习、参数辨识、状态更新、模型验证 |
| 新设计 | 关键材料与分子、界相、器件管理策略 | 电化学、相关尺度模拟、结构与性质关系、约束与多目标设计 |
| 新范式 | 科研智能体、逆向设计、自动化研究流程 | LLM 与 Agent、研究流程、工具连接、设计空间与评价方法 |

数字孪生方向需进一步理解观测数据如何更新模型、参数或状态；逆向设计方向需理解候选方案怎样经过物理和应用约束检验。这些专题随课题深入，不要求入门时全部掌握。

## 建议阅读顺序

1. 阅读研究定位，并初步了解[科研基本功](../06_科研基本功/README.md)，建立对科学问题、证据和研究记录的认识。
2. 同步学习[计算工具基础](../01_计算工具基础/README.md)和 [LLM 与 Coding Agent](../02_LLM与Coding_Agent/README.md)，掌握与 Agent 合作所需的基本语言。
3. 学习[机器学习与深度学习](../03_机器学习与深度学习/README.md)，先理解数据、模型和评价，再进入传统机器学习与深度学习。
4. 学习[电化学与电池基础](../04_电化学与电池基础/README.md)，围绕《电极过程动力学》建立对界面反应、传质与电池行为的认识。
5. 学习[模拟仿真基础](../05_模拟仿真基础/README.md)，了解 DFT、MD、MLFF、相场和 P2D 分别能回答什么问题，再结合已有机器学习和电化学知识理解 AI 融合方向。
6. 在课题推进中持续学习文献阅读、研究管理与科技论文写作，并深入相关模拟方法和 AI 专题；公式或物理基础不足时查阅[延伸阅读](../07_延伸阅读/README.md)。

以上是知识依赖关系，不是按周打卡的课程表。可从课题中的具体问题进入，再回到基础资料补足理解。

## 硕士与博士的学习深度

| 维度 | 硕士 | 博士 |
| --- | --- | --- |
| 共同基础 | 理解常用概念、基本工作流程及明显错误 | 同样掌握共同基础，并理解关键选择背后的依据 |
| 主方向 | 理解所用方法的输入输出、假设和局限 | 深入理解机制、近似与失效条件，能够比较方法并提出改进 |
| 相邻方向 | 知道可解决的问题及信息接口 | 理解跨方法连接所需的尺度、参数、误差和验证条件 |
| 科研判断 | 区分结果、解释与尚未验证的猜测 | 分析证据是否支持主张，辨识替代解释与方法贡献 |

学习深度取决于课题责任和研究问题，而非仅由学位决定。博士的“深入”主要体现在主方向和关键交叉接口。
