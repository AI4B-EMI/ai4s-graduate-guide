# 科研基本功

[返回首页](../README.md)

学习范围：**全员基础，贯穿实际课题**。目标是理解怎样阅读证据、推进问题、组织研究和表达结论。

## 三个部分

| 部分 | 需要补齐的知识 | 阅读入口 |
| --- | --- | --- |
| 文献阅读 | 检索、筛选、精读、原始证据、方法细节、知识整理 | [文献阅读](文献阅读/README.md) |
| 课题推进流程与管理 | 问题定义、假设与对照、研究决策、记录、协作、数据与版本 | [课题推进与管理](课题推进与管理/README.md) |
| 科技论文写作 | 科学主张、证据链、结构、图表、可复现方法、讨论与引用 | [科技论文写作](科技论文写作/README.md) |

文献阅读帮助判断问题与现有证据；课题推进产生能够回答问题的新证据；论文写作则检验研究逻辑是否清晰。三者应在研究中持续往返。

## 硕士与博士学习深度

| 硕士 | 博士 |
| --- | --- |
| 读懂课题相关论文；区分事实、解释与猜测；理解课题流程和记录要求；清楚表达方法、结果与局限 | 批判性整合文献；判断问题价值和研究空缺；分析替代解释并调整路线；组织具有清晰贡献和边界的论证 |

“深入”体现在科学判断，不以阅读论文数量、汇报页数或写作长度衡量。研究失败和负结果也可能澄清问题，应保留条件与证据。
