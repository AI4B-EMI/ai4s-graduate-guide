# 文献阅读

[返回科研基本功](../README.md) · [返回首页](../../README.md)

学习范围：**全员基础**。文献阅读服务于问题判断、方法选择和证据理解，不以读完多少篇作为目的。

## 需要补齐的知识

- **检索**：从研究问题提炼关键词与同义词；结合综述、原始论文、引文追踪和作者/主题检索。
- **筛选**：先看研究问题、核心图表、主要结论和方法适配性，判断是否值得精读。
- **精读**：识别作者的主张、直接证据、模型假设、数据来源、对照、统计与局限。
- **方法阅读**：查阅方法、补充信息、代码和数据，弄清参数、评价和可复现细节。
- **整合**：按问题组织文献，区分已有共识、争议、证据不足和本课题尚待回答的问题。
- **引用追溯**：区分综述转述和原始研究，核实关键数字与机制主张的原始出处。

## 怎样阅读一篇论文

先快速判断问题、贡献与相关性；再理解图表和证据结构；最后深入与课题有关的模型、公式和实现细节。这与 Keshav 的三遍阅读思路相通，具体顺序可按论文类型调整。

阅读模拟与 AI 论文时尤其关注：研究对象与工况、数据划分、基线、公平比较、物理假设、评价是否对应主张、外推与失效条件。漂亮图表和较高指标不能替代这些信息。

## LLM 辅助阅读

LLM 可帮助解释术语、定位问题和整理结构，但需要提供原文与来源。引用、公式解释、图表结论和方法细节应回到原文核验。检索到一条文献记录不代表已读过全文；摘要也不覆盖全部方法与局限。
