# 科技论文写作

[返回科研基本功](../README.md) · [返回首页](../../README.md)

学习范围：**全员基础，随实际研究深化**。论文写作首先是组织科学问题、主张与证据，再是语言与格式。

## 需要补齐的知识

| 主题 | 核心内容 |
| --- | --- |
| 问题与贡献 | 为什么研究、已有认识不足在哪里、本文新增什么 |
| 证据链 | 每项主张由哪些数据支持，证据能支持到什么程度 |
| 文章结构 | 标题、摘要、引言、方法、结果、讨论与结论的功能 |
| 图表 | 图表服务于哪个判断；单位、标签、图例、统计和条件是否明确 |
| 方法可复现 | 模型、软件版本、参数、数据、划分、评价与关键处理步骤 |
| 讨论与局限 | 与已有研究的关系、可能机制、替代解释、适用边界 |
| 引用与诚信 | 原始出处、合理转述、避免夸大、保留负结果与不确定性 |

## 模拟与 AI 论文特别需要说明什么

模拟研究应说明物理假设、边界条件、参数来源、收敛与采样，以及验证依据。AI 研究应说明数据来源、独立性、划分、基线、训练选择和评价条件。方法改进要能区分数据、算力、调参和架构各自的作用。

将电池应用结果提升为方法贡献时，应明确方法适用条件和可迁移部分。不能仅凭在一个体系中有效，就宣称适用于所有材料或器件。

## 硕士与博士学习深度

| 硕士 | 博士 |
| --- | --- |
| 理解各部分用途；清楚描述方法与结果；使用准确图表和引用；避免结论超过证据 | 能围绕核心问题组织贡献与论证；比较已有工作，分析替代解释与局限；判断哪些证据足以支持方法或机制主张 |

## AI 辅助写作

AI 可用于语言修改、结构讨论和术语整理，但作者需要检查是否改变因果关系、确定性、数值、比较对象或适用范围。核实每条引文，不用生成内容补造实验、计算过程或结果。具体使用与披露还应查目标期刊当前规则。
